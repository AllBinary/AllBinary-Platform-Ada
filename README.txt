                             AllBinary Platform Ada

What is it?

This repository contains code generated by the AllBinary Platform in Ada.  
This repo is used to allow developers to skip the Ada code generation step.

What are some examples game with this Ada code?

https://allbinary.itch.io (The downloads with "-ada" in the filename are Ada only builds. Currently that only includes nothing. Also the Ada builds are not available on Google Play or other stores.)
